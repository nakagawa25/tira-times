# PositionPicker

Chips de posição com múltipla escolha: Goleiro, Defesa, Ala, Meio, Ataque, Qualquer.

- **Qualquer** é o padrão e é exclusivo: escolhê-lo limpa os outros; escolher outra posição o desmarca; desmarcar tudo volta para Qualquer.
- Quem tem **Goleiro** entra como goleiro no sorteio (fixo no gol ou um por time, conforme Regras).
- Valor: array de ids `GOL | DEF | ALA | MEI | ATA | QQ`.
