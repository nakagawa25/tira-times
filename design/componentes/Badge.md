# Badge

Selo curto de status: Mensalista, Avulso, Goleiro ou aviso.

- `tone="monthly"` usa `gold-100`/`gold-800` e o ícone `workspace_premium`; texto padrão "Mensalista".
- `tone="guest"` neutro, texto padrão "Avulso".
- `tone="gk"` verde suave; `tone="warn"` para vagas abertas.

Na lista de jogadores prefira o ícone dourado ao lado do nome (já embutido no PlayerRow); o selo completo é para telas de detalhe.
